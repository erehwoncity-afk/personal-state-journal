隐私说明

Personal State Journal 是正在开发中的个人使用桌面程序。以下内容说明目前确定的数据处理设计；相关功能尚待实现，实际功能变更时本说明也会更新。

数据范围与用途

程序计划保存使用者填写的时间安排、完成情况、精力、情绪、身体感受和备注。在本人授权后，程序将读取授权范围内的 Oura 数据，例如睡眠、活动、准备度、心率、心率变异性、血氧、温度偏差、压力及运动记录，用于个人记录和回顾。具体读取范围以授权内容及 Oura 接口实际提供的数据为准。

保存与传输

日常记录和导入的身体数据计划保存在使用者电脑本地，授权凭据也仅供本机程序使用。同步 Oura 数据时，程序需要与 Oura 服务通信。设计中不设置用于接收个人记录的项目服务器，不将身体数据或授权凭据上传到本说明网站。

导出、删除与停止同步

程序计划提供按日期范围导出记录及删除本地记录的功能。导出文件及其副本由使用者管理。使用者可以停止同步，并通过 Oura 的授权管理撤销访问。撤销授权不会自动删除已经保存在电脑上的记录。

说明网站

这些说明页面不包含登录表单、身体数据上传功能、广告或项目自行添加的访问统计脚本。网站计划由 GitHub Pages 托管；托管服务可能按照其自身隐私声明处理访问日志等技术信息。

Oura 和 GitHub 对各自服务的数据处理分别适用其隐私政策。本项目可通过发布本说明的网站所关联的 GitHub 仓库 Issues 联系；公开讨论区不适合提交身体数据或授权凭据。
