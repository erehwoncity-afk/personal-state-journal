Personal State Journal
个人状态记录

这是一款正在开发中的个人使用 Windows 桌面程序，用于安排每日时间段、提供提醒，以及记录每个时间段结束后的完成情况、精力和身体感受。

计划功能包括：经本人授权读取 Oura 身体数据，将其与手动记录分别保存，并按日期范围导出。夜间身体指标和分时段自评将保留各自的时间范围与来源。

程序采用本地保存的设计。本网站只提供程序介绍、隐私说明和使用条款，不接收身体数据、日常记录或 Oura 授权凭据。

本程序为独立个人项目，与 Oura 无隶属关系，也不由 Oura 提供或背书。目前尚未提供公开下载。
