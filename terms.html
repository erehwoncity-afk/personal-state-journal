使用条款

用途与开发状态

Personal State Journal 是供本人使用的 Windows 状态记录项目，目前处于开发阶段，尚未提供面向公众的应用服务。计划功能包括提醒、手动状态记录、Oura 数据导入及记录导出。

Oura 连接

Oura 数据访问需要账户持有人授权，并受 Oura 接口、账户资格、会员状态及相关服务条款约束。接口、同步进度或服务变更可能导致数据延迟、缺失或连接中断。本项目与 Oura 无隶属关系。

记录与提醒的限制

记录用于个人整理与回顾，不提供医疗诊断或治疗。不同指标具有各自的采集时间和统计范围。电脑关机、休眠或系统通知设置可能影响提醒，程序无法保证任何情况下均按时通知。

本地文件管理

项目采用本地保存设计，记录及导出文件由使用者管理。开发过程可能调整存储格式及功能；涉及数据处理方式的变化将在隐私说明中更新。

联系

项目反馈可通过发布本说明的网站所关联的 GitHub 仓库 Issues 提交。
